# Level Up Learning: toolkit

Materials from the webinar "Level Up Learning: Building AI-Assisted Educational Games for Physiotherapy Students" (Dr. Harshal Sabané, Datta Meghe College of Physiotherapy, Nagpur, 26 November 2026).

Live site: https://indiandoctor.github.io/Level-Up-Learning/

| File | What it is |
|---|---|
| index.html | Landing page (the QR code on the last slide points here) |
| gait-detective.html | Gait Detective game: 10 gait cases, solo or teams |
| special-test-showdown.html | Special Test Showdown game: 12 MSK special tests |
| prompt-1-build-special-test-showdown.txt | Prompt used in the live build |
| prompt-2-add-practice-mode.txt | Follow-up prompt used in the live build |
| prompt-cookbook.pdf | Master template, five game recipes, tutor-mode prompts |
| level-recipe-card.pdf | LEVEL recipe and verification checklist |
| form2.html | Redirects to the session feedback form (set FORM2_URL inside the file) |

All games are single HTML files that work offline. Clinical content must be checked by a subject expert before use with students.
